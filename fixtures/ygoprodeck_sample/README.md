# YGOPRODeck sample snapshot

Hand-written, tiny sample shaped like the YGOPRODeck v7 `cardinfo.php` / `cardsets.php`
responses, used by tests and by `python -m imagetool.cli catalog load-sample`.
Names, set codes and rarities were written from memory and may contain mistakes — run
`python -m imagetool.cli catalog refresh` to load the real data.
